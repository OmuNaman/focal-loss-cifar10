# Research Statement

**Does focal loss beat cross-entropy for CIFAR-10 classification with a small CNN?**

_Date: 2026-06-04_

We investigate whether the focal loss (Lin et al., 2017), originally designed to address
foreground-background class imbalance in dense object detection, provides any accuracy benefit
over standard softmax cross-entropy when training a small convolutional neural network on the
balanced CIFAR-10 image-classification benchmark, and whether that conclusion changes under an
artificially induced class imbalance.
